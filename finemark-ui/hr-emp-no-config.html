Employee Number Format

Configure the employee number format for each employment type. Numbers follow the pattern PREFIX-TYPECODE-NNNN e.g. FM-PERM-0001. When an employee transitions to a new type their number is automatically regenerated. Each employee also has a permanent Personal File Number (5-digit) that never changes.

How employee numbers work

  • Employee numbers are formatted as PREFIX-TYPECODE-NNNN
  • When an employee changes employment type, a new number is auto-assigned for their new type; the old number is retired and recorded in the audit log.
  • Each person also has a Personal File Number (5-digit, e.g. 00001) assigned at onboarding that never changes — it is the permanent unique identifier regardless of type transitions.
  • Sequences are per type code — changing the type code resets the visible sequence for new employees but does not affect existing employees.
